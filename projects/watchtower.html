Sideband Watchtower

A Raspberry Pi ADS-B data-collection prototype with a local API/dashboard and a planned intelligence bridge into Artemis.

Why this project

Receiving aircraft broadcasts with a small SDR makes a useful systems-integration problem: physical RF equipment, stream decoding, a local data collector, a structured database, and a browsable map.

The system

Sideband Watchtower brings together SBS/BaseStation aircraft data ingestion, SQLite aircraft/event storage, and a FastAPI dashboard with a Leaflet map and aircraft detail views. The current build is being refined for repeatable setup and deployment.

Architecture and separation of responsibilities

An RTL-SDR receiver and ADS-B decoder provide the stream. The collector normalizes sightings and writes records. The dashboard/API exposes current data locally. The result is an inspectable local data pipeline from RF capture to a map interface.

Artemis integration roadmap

A future bridge will combine Watchtower aircraft data with National Weather Service alerts, traffic/incident feeds, and user travel plans. Deterministic rules can decide which events matter; Artemis can summarize those results and send a private Discord briefing.

Data integration plan

ADS-B provides the aviation picture. Traffic-aware routing, official weather alerts and incident feeds would add the ground-level context. Artemis is the proposed layer for bringing those sources together.

System flow

RTL-SDR / antenna→ADS-B decoder→Python collector→SQLite / FastAPI→Map / future Artemis bridge
