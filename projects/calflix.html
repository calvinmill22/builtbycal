SELF-HOSTED SERVICES

CalFlix

Operating a small private media service for real people—where onboarding, storage, connectivity, and reliability matter as much as setup.

The service

A privately hosted personal-media library accessible to an invited user community, designed to make a familiar application available without introducing unnecessary complexity.

Running the stack

A Linux Mint workstation hosts Jellyfin with external media storage. Tailscale provides access for authorized remote clients. I handle media organization, storage issues, account setup, and recurring connectivity questions.

Beyond the install

Once people depend on a service, they encounter client differences, authentication problems, network complications, and unexpected behavior. Supporting users provides feedback that a solo install cannot.

Operational lessons

Communicating setup steps clearly, distinguishing network problems from application problems, checking storage health and utilization, and keeping user expectations realistic are as important as installing the software.

Next improvements

Documented recovery steps, better health indicators, user onboarding automation, storage forecasting, and a clearer issue-reporting workflow.

System flow

Linux host→Media storage→Jellyfin→Private remote access→Invited users
